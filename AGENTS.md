# Exolon: перенос с melonJS

- Эталон реализации и поведения — соседний проект `../exolon` на melonJS.
- При каждом изменении игровой механики, графики, положения объектов, анимации или звука сверяй соответствующий код melonJS и наблюдаемое поведение работающей игры в браузере с реализацией и поведением в Godot. Указывай пользователю, если какую-либо часть проверки выполнить не удалось.
- Проверяй изменения в запущенном Godot, по возможности с помощью тестовых GDScript-сценариев. Игровую логику пиши на C#.
- После изменений запускай обновлённую игру в Godot, чтобы пользователь мог её увидеть.
