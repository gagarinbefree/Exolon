# Editing maps in Godot

Open `scenes/maps/L01S01.tscn` through `L03S25.tscn` in the 2D editor. Each scene contains the original map layers as `TileMapLayer` nodes and object groups as `Node2D` nodes. Paint existing atlas tiles in a layer, or move an object and edit its exported properties in the Inspector. The game reads those cells, object positions and properties, layer order, and `next_level` from the scene.

The `Collision` layer is hidden by default because melonJS uses it for physics rather than drawing. Toggle its eye in the scene tree to inspect or edit collision cells, and hide it again for the normal preview. Stars are generated by the game; the editor displays a fixed sample. Sprites that animate during play are shown in a fixed frame. Spawn markers and invisible trigger areas do not necessarily have a visible sprite in the game.

The game currently reconstructs its rendering from the scene's atlas cell IDs and the original tileset metadata. Editing tile artwork, changing atlas source IDs, transforming or hiding layers, and setting individual tile transforms are not yet supported as gameplay edits. The original TMX maps remain available for comparison until the conversion is accepted.

To compare every converted scene with its original map, run `python tools/export_tmx_manifest.py` and then run Godot with `--path . --script res://tools/compare_map_pixels.gd` with a display available. The comparison uses fixed frames for animated objects and a fixed star field, and writes images of the first differences to `artifacts/`. It is a local visual diagnostic, separate from the headless logic suite.
